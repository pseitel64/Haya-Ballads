# A Selection of Haya Epic Ballads

Ten recorded Haya epic ballad performances (Kagera Region, Tanzania) with synchronized audio, Haya transcription, English translation, and commentary.

- Live site: https://pseitel64.github.io/Haya-Ballads/
- Archived copy (download, works offline): https://doi.org/10.5281/zenodo.23344180

## How to cite

Seitel, Peter. *A Selection of Haya Epic Ballads: Synchronized Audio, Transcription, Translation, and Commentary (Digital Edition).* Zenodo, 2026. https://doi.org/10.5281/zenodo.23344180
